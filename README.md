# Manoir à Âmes

Jeu asymétrique tour par tour : une maison hantée qui grandit contre des
attaquants (touristes, fêtards, prêtres, militaires) de plus en plus coriaces.
Maquette 3D en un fichier (Three.js via CDN).

## Tester

Ouvrir `index.html` dans un navigateur (branche de la PR, puis `main` après merge).
